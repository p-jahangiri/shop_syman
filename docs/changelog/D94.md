# D94 — ساختار قابلیت‌های رابط و ثبت وابستگی‌های API

## تغییر

پس از مقایسهٔ خواندنی با سپهر و بک‌اند پارسه، صفحه، فرم، مدل و CSS مدیریت داده‌های کاتالوگ در `apps/admin/src/features/catalog-metadata` کنار هم قرار گرفتند. مسیر از ورودی پنل همچنان تنبل بارگیری می‌شود. در API، ثبت ۱۲ DbContext و تنظیم EF به `Shop.Api/Composition/DatabaseRegistration.cs` رفت. ترتیب ثبت، طرحواره‌ها و تاریخچهٔ migration در آزمون و بررسی اختلاف تأیید شدند. قواعد پوشه‌بندی در [معماری](../ARCHITECTURE.md) ثبت‌اند.

## فعال‌شده روی

ساختار سورس؛ دامنهٔ انتشار در سابقه.

## تأیید‌شده

۱۸۱۴ آزمون بک‌اند، ۸ آزمون هدفمند SQL، ۴۳۶ آزمون قرارداد پنل و ۲۴۸ آزمون پایتون گذشتند. بیلد پنل، بررسی TypeScript، ESLint و Prettier موفق بودند. پنل و API روی سرویس‌های اصلی فعال شدند. SQL اصلی ۹۴ migration و ۲۴۵ جدول داشت و فیکسچر آزمون باقی نماند. سلامت API، کاتالوگ فارسی و انگلیسی و پنل پس از جمع‌کردن خروجی‌های میانی پاسخ ۲۰۰ دادند.
