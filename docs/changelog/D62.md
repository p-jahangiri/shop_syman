# D62 — انتخاب موقعیت و پیش‌نمایش نشانی تکمیل شد

## تغییر

جریان مرجع مالک روی همان فروشگاه3000 فعال است: نقشه در ابتدای فرم، پنجرهٔ بزرگ و تمام‌صفحهٔ موبایل، جست‌وجوی واقعی استان/شهرستان/شهر، تأیید صریح و سپس پیش‌نمایش کوچک با «ویرایش موقعیت». ورود دستی مستقل است. نتیجهٔ شهرستان، انتخاب شهر معتبر می‌خواهد. جست‌وجو به مرکز تقریبی شهرستان می‌رود؛ خیابان یا مرکز دقیق شهر حدس زده نمی‌شود. انصراف/Escape، محدوده و نقطهٔ تأییدنشده را اعمال نمی‌کنند. نقطه فقط وارد فرم می‌شود و ذخیرهٔ نشانی جداست. کاشی بیرونی فقط پس از بازکردن صریح نقشه دریافت می‌شود.
