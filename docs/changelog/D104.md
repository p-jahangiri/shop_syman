# D104 — پالت فروشگاه به تفکیک بخش

## تغییر

رنگ برند اکنون زمینه، سربرگ و منوی موبایل، بنر اصلی، کارت کالا و دسته، کمپین‌ها، ویترین پیشنهادها و پانوشت را هماهنگ می‌کند. شدت رنگ خودکار سه حالت دارد. هر بخش در هر تم می‌تواند رنگ اختصاصی داشته باشد یا دوباره از برند پیروی کند. پیش‌نمایش روشن و تاریک رنگ‌های محاسبه‌شده را نشان می‌دهد. پس‌زمینهٔ بخش‌ها در بازهٔ خوانای همان تم قرار می‌گیرد و رنگ متن دکمه از کنتراست پس‌زمینه می‌آید.

## فعال‌شده روی

فروشگاه ۳۰۰۰، پنل ۳۱۷۳ و API ۵۰۸۰ روی Sayman؛ بدون مهاجرت.
