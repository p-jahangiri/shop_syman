# D96 — بسته‌های مستقل و ساختار ریشه

## تغییر

پنل و فروشگاه از بستهٔ صریح `@sayman/web-shared` استفاده می‌کنند و هر کدام دارایی‌های عمومی و تنظیم API خودشان را دارند. خروجی جداگانهٔ admin، storefront، api و database در ابزار بسته‌بندی در دسترس است. ساخت تمیز هر دو رابط از خروجی جدا و ساخت مستقل API موفق بود. تعریف Compose دیتابیس به `database` منتقل شد و همان volume محلی را معرفی می‌کند. فایل‌های تاریخی SQL کنار آن قرار گرفتند. مسیرهای سلامت و کاتالوگ عمومی در فایل‌های endpoint جدا قرار دارند. [راهنمای استقرار](../DEPLOYMENT.md) · [دیتابیس](../../database/README.md)

## فعال‌شده روی

بسته‌بندی سورس؛ دامنهٔ ساخت و اجرا در سابقه.

## تأیید‌شده

ابزارهای بررسی قرارداد در `scripts/verification`، ابزارهای محلی در `scripts/local`، و سناریوی تاریخی نسخهٔ ۸۵ در `tools/legacy/schema-85` قرار دارند. ۹۱۱ آزمون فروشگاه، ۴۳۶ آزمون پنل، ۲۴۸ آزمون ابزار، ۲۰۰ آزمون هدفمند API، ۲۶ آزمون SQL و ۷ بررسی قرارداد HTTP گذشتند. نسخه‌ها روی سرویس‌های اصلی فعال شدند. [انتشار رابط‌ها](../../artifacts/checks/frontend-quality-46772b8db4bc43daa868d1ece8b8552c-main-release.json) · [انتشار API](../../artifacts/checks/d96-api-final-release.json)

## تأیید‌نشده یا باز

حدود بررسی و موارد باز در سابقه آمده‌اند. این مدخل پذیرش تازه‌ای برای محیط تولید یا گردش‌های آزموده‌نشده ثبت نمی‌کند.
