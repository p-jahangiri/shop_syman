# D76 — جست‌وجو و کشف کالا

## تغییر

فروشگاه اصلی 3000 اکنون پیشنهاد املا را تنها برای جست‌وجوی خالی و پس از تأیید API با همان فیلترها نمایش می‌دهد. لینک نتیجهٔ سریع تنوع منطبق را باز می‌کند. صفحهٔ خارج از بازه به صفحهٔ اول همان فیلترها بازمی‌گردد. ۵۸ بررسی زنده، ۸۹۱ آزمون storefront، TypeScript، ESLint، Prettier و مرور فارسی/انگلیسی موبایل پذیرفته شدند. انتشار فقط storefront بود. [شواهد و مرحلهٔ بعد](../DELIVERY-CHECKLIST.md).
