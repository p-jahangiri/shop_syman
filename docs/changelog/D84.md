# D84 — میز کار محتوا، مجوز نویسنده و راه‌های تماس

## تغییر

پنل ۳۱۷۳ مقاله، صفحه، تنظیمات فروشگاه، تاریخچه و تغییر مسیر را در نماهای مستقل نشان می‌دهد. ویرایش مقاله و صفحه وضعیت پیش‌نویس، آمادگی دو زبان و پیوند نسخهٔ عمومی دارد. جست‌وجو و فیلتر روی ردیف‌های بارگذاری‌شده عمل می‌کنند. نقش «نویسندهٔ محتوا» پیش‌نویس مقاله و صفحه و تصویر عمومی را مدیریت می‌کند. انتشار، بازگردانی و لغو انتشار در API به مجوز مدیر محتوا نیاز دارند. سندهای تنظیمات پیش از انتشار یا بازگردانی تأیید می‌گیرند.
