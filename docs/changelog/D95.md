# D95 — پوشه‌بندی پنل، فروشگاه و بک‌اند

## تغییر

ریشهٔ `admin/src` فقط ورودی پنل را دارد و کد در پوشه‌های صفحه، اجزای مشترک، پوسته، قابلیت، API، نشست، وضعیت، هوک، ابزار و سبک قرار گرفت. اجزا و منطق فروشگاه در `components/<domain>` و `lib/<domain>` مرتب شدند و مسیرهای Next در `app` باقی‌اند. آزمون‌های هر رابط در پوشهٔ مستقل `tests` هستند. در بک‌اند، ورودی‌های HTTP و تراکنش‌ها از نقطهٔ راه‌اندازی جدا شدند. فایل‌های ماژول‌ها به پوشه‌های قرارداد، سرویس، خواندن، داده، تبدیل و قواعد رفتند و قراردادهای SharedKernel بر اساس حوزه گروه‌بندی شدند. [نقشهٔ پوشه‌ها](../ARCHITECTURE.md#محل-کد-هر-قابلیت)

## فعال‌شده روی

ساختار سورس؛ دامنهٔ انتشار در سابقه.

## تأیید‌شده

۹۱۱ آزمون فروشگاه، ۴۳۶ آزمون پنل، ۲۴۸ آزمون ابزار، ۱۸۱۴ آزمون بک‌اند و ۱۵ آزمون هدفمند SQL گذشتند. ساخت هر دو رابط، lint، Prettier و خروجی بسته‌بندی تولید تأیید شدند. انتشار روی سرویس‌های اصلی انجام شد. بررسی SQL اصلی ۹۴ migration و ۲۴۵ جدول را تأیید کرد و فیکسچر آزمایشی باقی نماند.
