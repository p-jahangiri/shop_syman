# D112 — میز کار و دسترسی سریع پنل

سربرگ میز کار بازطراحی شد و منتخب‌ها بالای گزارش‌ها قرار گرفتند. «رفتن به بخش» از نوار بالای تمام صفحه‌ها یا با `Alt + K` باز می‌شود. عبارت‌هایی مانند «ظاهر سایت» و «قیمت SKU» به بخش مرتبط می‌رسند. کلیدهای جهت‌دار و Enter برای پیمایش و بازکردن بخش و Escape برای بستن و بازگشت فوکوس به کار می‌روند.

منتخب‌های جست‌وجو و داشبورد مشترک‌اند. بخش‌های اخیر با ترتیب آخرین بازدید و سقف شش مورد نشان داده می‌شوند. تنظیمات برای هر حساب در همان مرورگر ذخیره می‌شوند. بازیابی منتخب‌ها و سابقه، نمایش نتایج و بازکردن مقصد از مجوز فعلی حساب پیروی می‌کنند.

۴۴۰ آزمون پنل، lint محدود و ساخت TypeScript پاس شدند. [انتشار محلی](../../artifacts/checks/frontend-quality-ba7e9b035d154fc9a63439bda8599542-main-release.json) شامل ۱۱ بررسی HTTP بود. [آزمون مرورگر](../../artifacts/checks/d112-admin-workspace/browser.json) دو حساب ساختگی با پاسخ‌های محدود به Chrome جداگانه، تم روشن و تیره، و عرض‌های ۳۹۰ و ۱۴۴۰ را پوشش داد. نشست واقعی مدیر برای بازبینی خصوصی جداگانه لازم است.
