# D65 — تاریخچهٔ مدیریتی قیمت و اصلاح جست‌وجوی فارسی فعال شدند

## تغییر

ادامه پس از پاسخ «مک باز شد»: Chrome قابل دسترسی شد، اما استفادهٔ هم‌زمان مالک پیش از ساخت تب QA کنترل را متوقف کرد. صفحه/فرم مالک تغییر نکرد و پذیرش خصوصی هنوز انجام نشده است؛ سؤال آزادبودن کوتاه Chrome ارسال شد. [گزارش تلاش](../../artifacts/checks/d65-native-chrome-unlock-attempt.json) به پذیرش قبلی مقید است و markerها همچنان pending هستند.

## فعال‌شده روی

فروشگاه، پنل و API محلی؛ schema ۸۸.

## تأیید‌شده

هر ۱۵۵۴ آزمون unit و ۲۵ SQL در پنج کلاس کامل با Counter برابر discovery/TRX و cleanup صفر پاس شدند. ۱۰۴۲ SQL کشف شد؛ اجرای کامل مجدد همهٔ آن‌ها ادعا نیست. شش فایل backend نسبت به D63 تغییر و ۱۴ DLL میان API/unit/SQL برابرند؛ فقط API/Catalog و PDB آن‌ها عوض شدند و ۱۲ ماژول دیگر بایت‌برابر ماندند. [پذیرش backend](../../artifacts/checks/catalog-price-history-backend/acceptance.json) و [خواندن پاسخ واقعی SQL در قرارداد/نمودار پنل](../../artifacts/checks/d65-price-history-sql-wire-ui.json). مرز rowversion انحصاری، زمان UTC با دقت هفت رقم و صفحه‌بندی بدون ورود append دیرهنگام در SQL آزموده‌اند؛ این گردش snapshot کامل SQL نیست.

## تأیید‌نشده یا باز

حدود بررسی و موارد باز در سابقه آمده‌اند. این مدخل پذیرش تازه‌ای برای محیط تولید یا گردش‌های آزموده‌نشده ثبت نمی‌کند.
