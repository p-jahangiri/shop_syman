# D59 — حساب مشتری و تداوم ورود

## تغییر

گردش حساب مشتری و محافظ تداوم ورود در انتشار مشترک باقی ماندند.

## فعال‌شده روی

نسخهٔ اصلی با schema ۸۶، در بستهٔ مشترک D57 تا D59.

## تأیید‌شده

شمارش ۱۴۳۰ unit، ۹۸۴ SQL و ۵۴ GET متعلق به کل [بستهٔ مشترک](D57.md#تأییدشده) است؛ شمارش مستقل برای این جزء ثبت نشده است.

## تأیید‌نشده یا باز

شاهد اجرای جداگانهٔ مجموعهٔ آزمون یا پذیرش خصوصی برای همین جزء ثبت نشده است.
