# D117 — نسخهٔ آزمایشی Docker روی آروان

مالک ظرفیت ماشین را به دو هسته و حدود چهار گیگابایت RAM ارتقا داد و دادهٔ نمونه خواست. نسخهٔ مستقل آزمایشی با Docker Engine 29.9.3 و Compose 5.7.0 راه افتاد. SQL Server 2022 Express در شبکهٔ داخلی است. API، فروشگاه، پنل و Nginx در کانتینرهای جدا هستند. پایگاه ۲۴۵ جدول، ۱۲ جدول تاریخچهٔ migration، ۱۲ کالای نمونه و چهار دسته دارد. از دیتابیس خالی و دادهٔ نمونه بکاپ گرفته شد و `RESTORE VERIFYONLY` پاس شد.

- [فروشگاه](https://server-8eb61a52-46d0-4b1a-9776-d511d93e2ffc.ir-thr-ba1.arvancompute.ir/fa) و [پنل](https://94.101.186.45/) از IP آزمایشگر بررسی شدند. صفحه‌های فارسی، انگلیسی، کاتالوگ، مجله و پنل HTTP 200 دادند. مسیر خصوصی پنل بدون ورود HTTP 401 داد.
- اعتبارسنجی Let’s Encrypt در دو روش به timeout رسید. گواهی اختصاصی آزمایش با SAN همان IP و دامنه از طریق HTTPS بررسی شد. دسترسی محدود به IP آزمایشگر است و گواهی برای مرورگر باید روی دستگاه تست مورد اعتماد قرار بگیرد.
- Runner غیر root با label اختصاصی در مخزن خصوصی ثبت شد. workflow تگ `test-vMAJOR.MINOR.PATCH` ساخت و کش تصویرها را در GitHub/GHCR انجام می‌دهد. اجرای خودکار فرمان ممتاز با متغیر مستقل غیرفعال می‌ماند تا دسترسی آن پذیرفته شود.
