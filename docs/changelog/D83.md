# D83 — کالای کارکرده و گردش چند منبع هلو

## تغییر

API ۵۰۸۰، پنل ۳۱۷۳ و فروشگاه ۳۰۰۰ روی SQL محلی Sayman با schema ۹۳ و ۲۴۴ جدول به‌روز شدند. میز کار کارکرده گزارش‌های ثبت‌شده را از SKUهای بدون گزارش جدا می‌کند. جست‌وجو از نام کالا، عنوان تنوع و SKU پشتیبانی می‌کند. چک‌لیست چهار دسته و خطای کنار فیلد درصد باتری افزوده شدند. کارت عمومی در صورت وجود، عکس همان نسخهٔ بازرسی SKU را انتخاب می‌کند. چهار نمونهٔ برچسب‌دار از فرمان Development وارد شدند و اجرای دوم بدون بازنویسی پایان یافت. چهار صفحه در هر دو زبان و جست‌وجوی نمونه‌ها در مرورگر بررسی شدند.
