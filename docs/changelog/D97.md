# D97 — فهرست سفارش و صف مرجوعی

## تغییر

فهرست سفارش بالای ابزارهای رزرو و رسید قرار گرفت. فیلد شماره، وضعیت و جست‌وجو هم‌تراز و واکنش‌گرا شدند. شماره با رقم فارسی پذیرفته و خطای ورودی کنار فیلد نمایش داده می‌شود. بازنشانی و پیام بدون نتیجه از فیلترهای واقعی پیروی می‌کنند. در مرجوعی، نوار جست‌وجوی جدول هنگام خالی‌بودن صف پنهان است. API برای فیلتر و وضعیت نمایشی سفارش از یک زمان مرجع استفاده می‌کند.

## فعال‌شده روی

پنل اصلی ۳۱۷۳.

## تأیید‌شده

۴۳۶ آزمون پنل، ۱۵۲ آزمون هدفمند بک‌اند و ۱۷ آزمون SQL گذشتند. ساخت، ESLint و Prettier موفق بودند. چینش تیره، اعتبارسنجی شماره، جست‌وجوی رقم فارسی، پاک‌کردن فیلتر و ورود به مرجوعی در Chrome با نشست مدیر بررسی شدند. صف اصلی سفارش خالی بود و پوشش ردیف‌های دارای داده از آزمون‌های SQL می‌آید. انتشار محلی API و پنل انجام شد. schema در ۹۴ مهاجرت و ۲۴۵ جدول باقی ماند و هیچ دیتابیس موقت آزمون باقی نماند.
