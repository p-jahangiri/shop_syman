# D63 — اعتماد و شبکه‌های اجتماعی روی اصلی فعال‌اند

## تغییر

بخش اختیاری storeIdentity درCMSهرزبان برایInstagram/Telegram/WhatsApp/Aparat/LinkedIn، اینماد/مجوز با لینک استعلام و تصویر اختیاری و مسیر صفحه‌های راهنما اضافه شد. مسیر پنل «محتوا و تنظیمات ← برند، منو و محتوای سایت ← اعتماد، شبکه‌های اجتماعی و راهنمای فروشگاه» است. save/publish/restore همان مجوز/MFA/CAS/audit/تاریخچه را حفظ می‌کنند؛ HTML/JS دلخواه، URL اجرایی/credential/دامنهٔ مشابه و تصویر مجوز محلیِ غیرReady رد می‌شود. سیاست CSP باز نشده است. [راهنمای مدیریت](../STORE-IDENTITY.md) و [پذیرش مستقل](../../artifacts/checks/store-identity-acceptance.json).

## فعال‌شده روی

محیط محلی در زمان ثبت؛ دامنهٔ بسته‌ها و سرویس‌ها در سابقه.
