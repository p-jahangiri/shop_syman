# D103 — خوانایی رنگ دکمه در هر دو تم

## تغییر

مدیر رنگ پس‌زمینهٔ دکمه را برای هر تم انتخاب می‌کند. متن با بیشترین کنتراست از سیاه و سفید تعیین می‌شود. لینک‌ها در سطوح عادی از طیف خوانای همان رنگ استفاده می‌کنند. پنل پیش‌نمایش هر دو تم و نسبت کنتراست را نشان می‌دهد. حالت هاور کنتراست متن را حفظ می‌کند و مرور سبک هم طیف خوانای تم روشن را می‌گیرد.

## فعال‌شده روی

فروشگاه، API و پنل اصلی؛ بدون مهاجرت.

## تأیید‌شده

unit-tested: ۹۱۷ فروشگاه، ۴۳۸ پنل و ۶۱ بک‌اند. SQL-tested: ۳ سناریو. browser-verified: کنتراست چهار کنترل در Chrome.

## تأیید‌نشده یا باز

پنل با نشست مدیر در این اجرا بازبینی نشد.
