# D114 — حفظ ویرایش پالت‌های آماده

ویرایشگر پنل، پالت انتخاب‌شده و رنگ‌های پالت‌های دیگر را در پیش‌نویس CMS نگه می‌دارد. جابه‌جایی میان پالت‌ها، رنگ‌های روشن و تاریک، رنگ بخش‌ها و شدت هر پالت را حفظ می‌کند. کلیک دوباره روی همان پالت، ویرایش را بازنشانی نمی‌کند. پالت سفارشی قبلی قابل انتخاب است و بازنشانی پالت فعلی یا استفاده از پیش‌فرض فروشگاه، ویرایش بقیهٔ پالت‌ها را نگه می‌دارد.

«ذخیرهٔ پیش‌نویس» همهٔ تغییرات را در سند تنظیمات مشترک ثبت می‌کند. «انتشار» رنگ‌های پالت انتخاب‌شده را در هر دو زبان اعمال می‌کند. API فقط همان پالت را به بازدیدکننده می‌دهد.

۴۴۲ آزمون پنل، ۳۹ آزمون واحد API و سه آزمون SQL پاس شدند. آزمون SQL ذخیره، انتشار در هر دو زبان، رد پالت نامعتبر و بازگردانی سند پیشین را بررسی کرد. دیتابیس موقت جمع شد. پنل و API روی نسخهٔ محلی ۹۴/۲۴۵ فعال شدند.
