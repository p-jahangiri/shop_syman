# D68 — تغییر رمز شخصی و اصلاح تجربهٔ ورود مدیر پذیرفته و فعال شد

## تغییر

پس از خطای ورود، سرویس‌ها سالم و admin فعال/بدون قفل بود؛ رمز موجود در مقایسهٔ خصوصی مجاز مطابقت داشت. ورود عادی با همان رمز و MFA مالک شمارنده را از۴به۰ برد؛ reset/unlock/MFA bypass انجام نشد. [تشخیص](../../artifacts/checks/d68-admin-login-diagnosis.json). مالک خواست مشکل تکرار نشود. فرم تغییر رمز شخصی با رمز فعلی+TOTPتازه، نمایش رمز/Caps Lock و راهنمای ورود کارکنان اضافه شد. موفقیت به‌صورت اتمیک hash/stamp/counter/audit و ابطال همهٔ نشست‌هاست؛ نقش/Authenticator/کدهای پشتیبان محفوظ‌اند. نتیجهٔ مبهم دوباره ارسال نمی‌شود و هیچ رمز در storage/journal ذخیره نمی‌شود. [راهنمای دسترسی](../ADMIN-ACCESS.md).

## فعال‌شده روی

API ۵۰۸۰ و پنل ۳۱۷۳؛ schema ۸۹.
