# D118 — انتشار خودکار تگ روی آروان

پس از تأیید مالک، Runner اختصاصی فقط اجازهٔ اجرای فرمان root-owned انتشار با SHA-256 مشخص و آرگومان خالی را گرفت. نسخهٔ `sudo-rs` آروان قید digest را پشتیبانی نمی‌کرد. سیاست محدود در `sudo.ws` جداگانه تنظیم شد. آزمون‌های مجوز، رد اجرای مستقیم Docker، shell و آرگومان اضافه را تأیید کردند. SHA نهایی فرمان `0ff5f011e79484a199aafd37dd598a9f9d89f60018b8c70b6262024ccd9efda6` است.

تگ `test-v0.1.1` در تلاش اول به‌دلیل قالب جدید توکن GitHub در مرحلهٔ اعتبارسنجی رد شد. سازگاری با قالب نقطه‌دار اضافه شد و فقط مرحلهٔ انتشار با همان سه تصویر تکرار شد. CI بکاپ و اعتبارسنجی SQL، آرشیو کلیدهای برنامه، اجرای فرمان migration و سلامت سرویس‌ها را گذراند. [اجرای CI](https://github.com/p-jahangiri/shop_syman/actions/runs/42597831107/attempts/2)

نسخهٔ فعال با سه digest منتشرشده تطبیق دارد. کانتینر SQL همان کانتینر پیشین است و ۲۴۵ جدول، ۹۴ migration، ۱۲ کالای نمونه و چهار دسته مشاهده شدند. خانهٔ فارسی و انگلیسی، کاتالوگ، مجله و پنل از بیرون با HTTPS پاسخ ۲۰۰ دادند و درخواست ناشناس مسیر خصوصی پنل پاسخ ۴۰۱ گرفت. این نسخه برای آزمایش با همان گواهی اختصاصی و محدودیت IP میزبان D117 در دسترس است.
