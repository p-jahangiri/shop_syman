# D119 — یک IP برای فروشگاه و پنل آزمایشی

تگ [`test-v0.1.2`](https://github.com/p-jahangiri/shop_syman/actions/runs/42601432373) روی همان نصب آروان منتشر شد. [فروشگاه فارسی](https://94.101.186.45:8443/fa)، [فروشگاه انگلیسی](https://94.101.186.45:8443/en) و [پنل](https://94.101.186.45/) از یک IP با دو پورت HTTPS باز می‌شوند. نام قبلی فروشگاه با ۳۰۸ به نشانی جدید هدایت می‌کند و مسیر و پارامترها را نگه می‌دارد. نشانی در فایل اجرایی خود پنل نیز به‌روز شد.

- **پذیرش HTTPS:** خانهٔ فارسی و انگلیسی، کاتالوگ، مجله و پنل ۲۰۰؛ مسیر خصوصی ناشناس ۴۰۱. خروج بدون نشست با کوکی حذف امن در هر دو رابط ۲۰۴، مبدأ اشتباه ۴۰۳ و کوکی تکراری ۴۰۰. این آزمون از حساب مدیر یا مشتری استفاده نکرد.
- **داده و دسترسی:** همان کانتینر SQL با ۲۴۵ جدول، ۹۴ migration، ۱۲ کالای نمونه و چهار دسته پابرجاست. بکاپ SQL و بستهٔ بازیابی کلیدها ثبت شدند. Nginx فقط کوکی‌های رابط مربوط را به آن برنامه می‌فرستد. API و SQL پورت عمومی ندارند؛ دسترسی آزمایشی به IP مجاز محدود است و همان گواهی اختصاصی آزمایش برای دستگاه تست لازم است.
