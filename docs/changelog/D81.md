# D81 — پژوهش خوراک مجاز کاتالوگ تأمین

## تغییر

نیاز به خوراک مجاز برای انتخاب تنوع و ثبت درخواست تأمین بررسی شد. پیشنهاد پژوهش، نمونه و مجوز واقعی تأمین‌کننده می‌خواست. D82 ادامهٔ مسیر بازار را از سایت و پنل کنار گذاشت.

## فعال‌شده روی

هیچ اتصال یا خوراک زنده‌ای برای این برش فعال نشده است.

## تأیید‌شده

دامنهٔ درخواست و پیشنهاد پژوهش ثبت شده‌اند. آزمون یا شمارش پذیرش اتصال برای این برش ثبت نشده است.

## تأیید‌نشده یا باز

ارائه‌دهنده، قرارداد، اعتبار داده و اتصال واقعی تأیید نشده‌اند؛ این مسیر در صف اجرای فعلی نیست.
