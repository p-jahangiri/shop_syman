# D86 — مشتریان، صندوق پشتیبانی و عکس دیدگاه

## تغییر

فهرست مشتریان در دسکتاپ جدول و در عرض کم کارت است. جست‌وجو، وضعیت و نوع حساب در API فیلتر می‌شوند و هر ردیف به بخش‌های مجاز پرونده، سفارش و پشتیبانی راه دارد. صندوق پشتیبانی تعداد واقعی هر صف را نشان می‌دهد. شمارهٔ کامل پیگیری در همهٔ صف‌ها پیدا می‌شود؛ فیلتر عنوان روی تیکت‌های دریافت‌شده است. عکس همراه پاسخ در گفت‌وگوی موجود انتخاب و پیش‌نمایش می‌شود. دریافت عکس فقط برای طرف مجاز گفت‌وگو انجام می‌شود. ذخیرهٔ خصوصی رمزگذاری‌شده و اسکن ClamAV در نسخهٔ محلی فعال‌اند.

## فعال‌شده روی

محیط محلی در زمان ثبت؛ دامنهٔ بسته‌ها و سرویس‌ها در سابقه.

## تأیید‌شده

بکاپ SQL تأیید و فقط مهاجرت Reviews اعمال شد؛ اثرانگشت ردیف‌های قبلی حفظ شد و Sayman به schema ۹۴ رسید. هر دو رابط روی همان ۳۰۰۰ و ۳۱۷۳ با API ۵۰۸۰ فعال‌اند. ۲۶ آزمون SQL، ۸۹۹ فروشگاه، ۴۲۶ قرارداد پنل، ۵۹ آزمون پراکسی و ۱۸ بررسی HTTP زنده گذشتند. Chrome با نشست مدیر پروندهٔ مشتری، چهار صف، کنترل پیوست و عکس دیدگاهِ منتشرنشده را نشان داد؛ در مرورگر داخلی هم ستاره‌ها، نشان نمونه و عکس منتشرشده دیده شدند.
