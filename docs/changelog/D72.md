# D72 — جست‌وجو، فیلتر و مرتب‌سازی در خود جدول کالا

## تغییر

کنار عنوان هر ستون داده دکمهٔ فیلتر قرار گرفت؛ عنوان ستون ترتیب را تغییر می‌دهد و پنجرهٔ همان ستون نیز صعودی/نزولی دارد. نوع فیلتر متناسب با ستون است: نام، دسته، برند، وضعیت، بازهٔ قیمت پایه/تعداد/موجودی، و بازهٔ تاریخ شمسی. جست‌وجوی نام و SKU همیشه بالای جدول در دسترس است. فیلترها ترکیب می‌شوند، روی کل نتایج قبل از صفحه‌بندی اجرا می‌شوند و جداگانه یا یکجا قابل حذف‌اند. برای ستون خارج از دید یا پنهان، منوی «فیلتر و ترتیب ستون‌ها» در دسترس است.

## فعال‌شده روی

محیط محلی در زمان ثبت؛ دامنهٔ بسته‌ها و سرویس‌ها در سابقه.

## تأیید‌شده

API و پنل اصلی به‌روز شدند؛ schema ۹۳/۲۴۴ جدول و نسخهٔ فروشگاه ثابت‌اند. ۴۰۱ آزمون پنل، ۵۸ آزمون واسط، ۱۹ آزمون واحد مرتبط و ۷ آزمون SQL مرتبط موفق شدند؛ پایگاه‌های موقت پاک شدند. واسط هم فیلتر معتبر را عبور می‌دهد و تکرار کلید یا تاریخ/عدد نامعتبر را رد می‌کند. [انتشار API](../../artifacts/checks/d72-api-release.json) و [انتشار پنل](../../artifacts/checks/frontend-quality-a63fe248b27b47228d423beee438aa49-main-release.json).

## تأیید‌نشده یا باز

حدود بررسی و موارد باز در سابقه آمده‌اند. این مدخل پذیرش تازه‌ای برای محیط تولید یا گردش‌های آزموده‌نشده ثبت نمی‌کند.
