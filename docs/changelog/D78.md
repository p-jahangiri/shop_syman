# D78 — تجربهٔ مدیریت کالا و نمایش ویدیو

## تغییر

نسخهٔ محلی پنل و فروشگاه با نمای فشرده و ستون‌های به‌یادماندنی، رنگ وضعیت‌ها، جست‌وجوی فیلدها و تنوع‌ها و نمایش دامنهٔ ویدیو به‌روز شد. گالری فروشگاه از تنوع فاقد ویدیو به تنوع دارای ویدیو راه می‌دهد. پخش ویدیوی A10 در مرورگر کامل شد و نمایش ویدیوی عمومی آیفون ۱۵ برای چهار تنوع در هر دو زبان بررسی شد. API و دادهٔ کالا برای این انتشار ثابت بودند. [شواهد پذیرش](../DELIVERY-CHECKLIST.md).

## فعال‌شده روی

محیط محلی در زمان ثبت؛ دامنهٔ بسته‌ها و سرویس‌ها در سابقه.
