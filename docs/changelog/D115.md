# D115 — پرسش‌وپاسخ عمومی و مجلهٔ فارسی

- پشتیبان کالای منتشرشده را با نام از کاتالوگ انتخاب می‌کند و پیش‌نمایش پیشنهاد را می‌بیند. پیام‌های قبلی دارای پیوند پیشنهاد همچنان خوانده می‌شوند.
- تب پرسش‌وپاسخ کنار دیدگاه‌ها، جست‌وجو و ثبت سؤال دارد. مدیر دارای مجوز پشتیبانی و انتشار می‌تواند متن را بازبینی و با تأیید صریح عمومی کند. ثبت پیام خصوصی و انتشار عمومی در یک تراکنش انجام می‌شوند. تلاش دوبارهٔ همان فرمان، پیام یا پرسش تکراری ایجاد نمی‌کند. صفحهٔ کالا فقط متن بازبینی‌شده، پاسخ و تاریخ را می‌گیرد.
- مجله با نمای تصویری، راهنمای خرید، مقایسه و خبر فارسی موبایل بازطراحی شد. تیتر و پیوند زومیت و دیجیاتو از خوراک عمومی می‌آیند. تصویرهای کارت‌ها موضوعی و از دارایی‌های خود فروشگاه‌اند. در بررسی زنده شش تیتر از هر دو منبع مشاهده شد.

آزمون‌ها شامل ۹۲۷ فروشگاه، ۴۴۲ پنل، سه واحد API و ۱۷ SQL بودند. آزمون تازهٔ انتشار به‌طور جداگانه اجرا شد تا سهمیهٔ ورود فیکسچر مشترک روی نتیجه اثر نگذارد. SQL مجوزها، انتشار متن بازبینی‌شده، پاسخ خصوصی، جلوگیری از تکرار و مرز زبان را پوشش داد. دیتابیس‌های موقت جمع شدند. بسته‌ها روی همان نسخهٔ محلی با ۹۴ migration و ۲۴۵ جدول فعال‌اند.
