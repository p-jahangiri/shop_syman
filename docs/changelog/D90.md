# D90 — بازطراحی فروشگاه و LinkedIn

## تغییر

خانه، جست‌وجو، کارت و جزئیات کالا، پشتیبانی و پانوشت بازطراحی شدند. مجموعه و برند از دادهٔ کاتالوگ و تنظیمات منتشرشده استفاده می‌کنند. حرکت از تنظیم پنل و ترجیح کاهش حرکت دستگاه پیروی می‌کند. دکمهٔ ویدیو به تنوع مرتبط می‌رسد. افزودن سریع از روش‌های خرید فعال پیروی می‌کند. هشدار عمومی پیش‌نمایش از تجربهٔ متصل به API برداشته شد. کالاها و متن‌های از قبل برچسب‌خوردهٔ توسعه و تشخیص محیط همچنان قابل تفکیک‌اند.

## فعال‌شده روی

محیط محلی در زمان ثبت؛ دامنهٔ بسته‌ها و سرویس‌ها در سابقه.

## تأیید‌شده

۹۰۶ آزمون فروشگاه، ۴۳۶ پنل، ۵۹ پراکسی و پنج آزمون SQL هویت فروشگاه موفق شدند. TypeScript، ESLint، قالب‌بندی و ساخت گذشتند. جست‌وجوی زنده، فوکوس Escape، فیلتر Anker، منوی ۳۹۰ پیکسلی و تم تیره در مرورگر بررسی شدند. پیوند کارت کالا پخش‌کنندهٔ تنوع را مستقیم باز کرد و زمان پخش ویدیوی چهارثانیه‌ای به ۳٫۱ ثانیه رسید. چهار درخواست Range برای دو ویدیو و دو زبان `206 video/mp4` گرفتند. نسخه‌های محلی روی ۳۰۰۰/۵۰۸۰/۳۱۷۳ فعال‌اند. مهاجرت لازم نبود و فیکسچر SQL باقی نماند.

## تأیید‌نشده یا باز

حدود بررسی و موارد باز در سابقه آمده‌اند. این مدخل پذیرش تازه‌ای برای محیط تولید یا گردش‌های آزموده‌نشده ثبت نمی‌کند.
