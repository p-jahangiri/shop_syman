# دسترسی به کاتالوگ بازار از منوی CMS

منوهای دسکتاپ، موبایل و فوتر از سند `site/{locale}` می‌آیند. فرم موجود پنل امکان انتخاب `/market`، عنوان دلخواه، ترتیب و زیرمنو را دارد؛ لینک در رابط فروشگاه hardcode نمی‌شود. وضعیت انتشار هر زبان جدا و snapshotهای قبلی محفوظ‌اند.

برای نمونهٔ محلی موجود، فرمان `--market-navigation-dev` به‌صورت پیش‌فرض فقط dry-run است. `--market-navigation-dev --apply` در Development، پس از بررسی هر دو زبان، فقط یک لینک «کاتالوگ بازار / Market catalogue» به CMS می‌افزاید و با ContentService نسخهٔ انتشار می‌سازد. actor تاریخچه `development-seed:market-navigation` است؛ حساب مدیر یا مجوز تازه‌ای ساخته نمی‌شود. این ابزار endpoint عمومی ندارد و در Production پیش از resolve سرویس‌ها رد می‌شود.

پیش‌نویس با انتشار جاری به‌صورت ساختاری مقایسه می‌شود؛ تفاوت تجاری یا محتوایی موجب توقف کامل است. نبود سند/انتشار هر زبان یا منوی پُر هم هر دو زبان را بدون تغییر می‌گذارد. لینک موجود در هر سطح با همان عنوان و زیرمنو حفظ می‌شود. افزودن لینک، سایر فیلدها و ترتیب آیتم‌های قبلی را عوض نمی‌کند. عملیات واقعی هر دو زبان در transaction Serializable است؛ rowversion و ContentService معتبر باقی می‌مانند. تکرار، revision یا Version تازه‌ای نمی‌سازد.

این لینک دادهٔ بازار یا موجودی/قیمت قابل پرداخت تولید نمی‌کند. مسیر بازار همان API مجاز/CSV و گردش درخواست تأمین قبلی را دارد. کارکرد draft preview/page builder پیشرفته و پذیرش موبایل جدا باقی‌اند.

دو آزمون SQL تازه dry-run بی‌نوشتن، حفظ تمام محتوای قبلی، لینک تو در تو با عنوان سفارشی، تکرار بدون تغییر، توقف atomic در draft/full/missing و منع Production را پذیرفته‌اند.۸۶۶ واحد/کل۵۶۹ SQL واقعی و build بدون هشدار موفق‌اند؛۱۳ DLL در unit/SQL/harness همسان است. دو metadata خام SQL با snapshotSchema تولیدی پذیرفته‌اند. مرورگر GUID مستقل، FA/EN header/footer، کلیک بازار و سه مدل نمونه، ویرایشگر منوی پنل و revision2 خود QA را تأیید کرد. موجودی/کاتالوگ/مالی ثابت ماندند و QA کامل پاک شد. desktop1280 پذیرفته و mobile باز است.

محلی پس از dry-run بی‌نوشتن و بکاپ تازه۱۸٬۹۹۳٬۱۵۲بایت وVERIFYONLY، فقط لینک بازار و دو revision CMS جدید ذخیره شد. revision هر زبان3 است؛ auth1/تمام۱۲۷ جدول دیگر و همهٔ محتوای قبلی و ترتیب منو دقیقاً محفوظ‌اند. تکرار واقعی CLI بی‌نوشتن بود؛ پس از۲۲۵ HTTP هر۱۲۹ جدول برابرند. schema/HTTP artifacts و ساخت فروشگاه/پنل تغییر نکردند. API برای backup/CMS متوقف و همان artifact هلو۴۷ دوباره اجرا شد. ابزار ثابت `tmp/market-navigation47-runtime.json` و `artifacts/checks/market-navigation47-main-release.json` مرجع‌اند. snapshot قبل از۴۷ و قبل از منو هر دو محفوظ‌اند؛ انتشار اصلی/Production یا سیاست تجاری از این توسعه نتیجه نمی‌شود.

برای نصب محلی تازه، `python3 scripts/backend-local.py --market-navigation-dev` فقط بررسی می‌کند و افزودن `--apply` صریحاً دادهٔ Development را منتشر می‌کند. ویرایش‌های بعدی از پنل CMS انجام می‌شوند؛ ابزار draft مدیر را جایگزین نمی‌کند. هیچ endpoint ورود یا مجوز تازه‌ای ساخته نشد.
