# لحظهٔ سایمان / Sayman Moments

وضعیت 2026-10-23: برش PROMO-01 با CMS واقعی و SQL محلی پیاده و در API/HTML پذیرفته شده است؛ بازبینی تصویری دسکتاپ فارسی و موبایل FA/EN در ادامه پذیرفته شد؛ CWV هنوز پذیرفته نیست. نام فعلی نمونه است و مدیر آن را تغییر می‌دهد. این قابلیت باقی پروژه/بازار/دست‌دوم/نظرات را کامل نمی‌کند.

## رفتار

نوع تأییدشدهٔ `spotlight` در homeBlocks، عنوان/متن/دکمه/ترتیب، انتخاب دستی۱–۲۴ کالا، سقف نمایش خانه۱–۲۴ و زمان شروع/پایان UTC دارد. شروع شامل و پایان خارج است. بلوک غیرفعال می‌تواند پیش‌نویس ناقص داشته باشد؛ برای فعال‌شدن عنوان و انتخاب صریح لازم است. پنل همان ProductPicker محدود و نسخه‌دار CMS را مصرف می‌کند؛ نقش و MFA و publish/rollback قبلی برقرارند.

خانه بخش بنری با گرافیک همان کالاها و کارت‌های عادی می‌سازد؛ `/fa/moments` و `/en/moments` همهٔ کالاهای مجموعه‌های فعال را به ترتیب انتخاب نشان می‌دهند. در نبود مجموعه/کالای منتشرشده حالت خالی واضح است. lookup عمومی حداکثر۲۴ شناسه در هر بلوک است؛ محصولات پنهان/غایب با کالای دیگر یا کل کاتالوگ پر نمی‌شوند. ساختار مشتق‌شده در localStorage ذخیره نمی‌شود. پاسخ‌ها از API واقعی و no-store هستند.

عضویت در مجموعه، قیمت، موجودی، روش/طرح خرید یا رزرو را تغییر نمی‌دهد. compareAt و قیمت تنوع انتخاب‌شده، همان مقدار فعلی Catalog و ریال رشته‌ای است؛ خود برچسب ویژه ادعای تخفیف درصدی ندارد. مدیر توضیح شرایط را می‌نویسد؛ اعمال شرایط مالی همچنان از تنظیم کالا/طرح و quote سروری است. شمارش معکوس یا فوریت ساختگی وجود ندارد. در صورت زمان پایان، تاریخ مطلق تهران با تقویم/ارقام زبان جاری نمایش داده می‌شود. زمان‌بندی هنگام SSR تازه اعمال می‌شود؛ حذف آنی از صفحهٔ ازقبل‌بازشده تضمین نشده است.

انیمیشن تزئینی ورود کمتر از یک ثانیه و نور۲٫۶ثانیه فقط یک بار با prefers-reduced-motion:no-preference اجرا می‌شوند. rail خانه در موبایل scroll دستی دارد؛ صفحهٔ کامل grid است. این توصیف کد پیاده‌شده است، شاهد تصویری/دستگاهی نیست.

## دادهٔ نمونه و ارتقای محیط موجود

fixture و `backend/Seed/development.json` دو زبان، مجموعهٔ p2/p6/p8/p1 و برچسب روشن نمونه دارند. seed تازهٔ Development آن را درج می‌کند؛ seed عمومی قبلی اسناد CMS موجود را بازنویسی نمی‌کند. برای SQL محلیِ قبلاً seedشده فرمان مستقل زیر اضافه شد:

```sh
python3 scripts/backend-local.py --seed-moments-dev
```

این فرمان فقط در Development و روی schema آماده اجرا شود. هر دو زبان در transaction Serializable متعلق به CMS ذخیره/منتشر و ContentRevision با actor=development-seed:moments ثبت می‌شوند. وجود draft منتشرنشده، برخورد شناسه یا سند غایب فرمان را متوقف و transaction را rollback می‌کند؛ مجموعهٔ spotlight موجود حفظ و اجرای تکراری بی‌تغییر است. هیچ endpoint عمومی، credential یا موفقیت provider افزوده نشده است. فرمان، اجازهٔ seed Production یا تغییر قیمت/موجودی/سیاست مالی ندارد.

D27 مجوز دادهٔ نمونهٔ قابلیت درخواستی را داده است؛ در اصلی محلی هر دو CMS از revision1 به2 رفتند و اجرای دوباره هر دو را۲ نگه داشت. پیش از آن، بکاپ COPY_ONLY/CHECKSUM/VERIFYONLY اصلی۱۷ و key ring خصوصی حفظ و چهار migration افزایشی اصلی را به۲۱ رساندند. D22 فقط آزمون قدیمیِ QA بود و به انتشار اصلی تعمیم داده نشد.

- ۱۲۰/۱۲۰ تست فروشگاه، شامل زمان مرزی/انتخاب صریح/قیمت بدون تغییر و parser؛۴۳۵/۴۳۵ واحد backend؛ typecheck و build پنل و build عادی Next موفق‌اند.
- سه SQL Commerce با MFA واقعی، auth guard، draft/publish،409 نسخهٔ قدیمی، حفظ قیمت‌ها، حذف کالای Hidden از lookup و rollback رشته‌ای موفق‌اند. اولین اجرا۲موفق/۱شکست بود: آزمون به ترتیب variant[0] تکیه کرده بود و اکنون SKU مشخص را بررسی می‌کند؛ خطای دامنه نبود.
- یک SQL مستقل دیگر Production guard، عدم دست‌کاری draft، rollback بین دو زبان و بی‌تکراری درج نمونه را تأیید کرد. baseline پیشین۱۲۹ SQL موفق بود؛ مجموعهٔ کامل۱۳۱تایی تازه دوباره اجرا نشده است.
- ۱۴ smoke عمومی PWA/locale/metadata و۱۴ HTTP مربوط به home/moments/order/account/address/cart و private401 روی Next واقعی/API5080/SQL۲۱ موفق‌اند؛ چهار کالای انتخابی و ترتیب در دو زبان تطبیق داده شد. این HTTP جای مرورگر/موبایل/پرداخت نیست.
- فایل‌های moments-* در artifacts/checks شواهدند؛ main-pre21-* بکاپ/ارتقا را ثبت می‌کنند. build نخست sandbox در compile معلق شد و پس از توقف فقط processهای خودش، build با IPC مجاز در۱٫۲ثانیه compile و کامل شد؛ شاهد اول حفظ است.

در ادامه ابزار مستقیم CUA با مستندات خودش در دسترس بود؛ تصاویر moments-main-desktop-fa.jpg و moments-main-mobile-fa/en.jpg از Next3000/SQL اصلی گرفته شدند. تغییر زبان مسیر /moments را حفظ کرد، عرض سند در viewport390 برابر375 و بدون overflow و console صفر بود. انتخاب‌های قبلی مرورگر دست‌کاری نشدند. این شاهد visual است؛ اندازه‌گیری reduced-motion/CWV و دستگاه مستقل نیست. مجموعهٔ کامل۱۵۲ SQL جدید تمام SQLهای پیشین را هم با صفر fail/skip پذیرفت. Production، provider، پرداخت/ارسال واقعی و زمان‌بندی حذف زندهٔ بلوک از صفحهٔ باز خارج از این پذیرش‌اند.
