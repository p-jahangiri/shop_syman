# مقایسهٔ محصول و تنوع

وضعیت: پیاده‌سازی و پذیرش SQL/دسکتاپ انجام شده؛ پذیرش واقعی عرض موبایل و انتشار این برش هنوز باز است. سند وضعیت جاری و runtimeها در STATUS است.

- دو تا چهار محصول یک دسته از جست‌وجوی محدود یا انتخاب‌های ذخیره‌شده/لینک عمومی خوانده می‌شوند. انتخاب هر SKU، قیمت ریالی رشته‌ای، موجودی آزاد، گارانتی و override مشخصات همان تنوع را نمایش می‌دهد. قیمت تومان با BigInt و اعشار یک‌دهم نمایش داده می‌شود؛ تبدیل به Number ندارد.
- ترتیب و قابلیت مقایسه از قواعد دستهٔ SQL می‌آیند. مقادیر Text/Number/Bool/Select/MultiSelect در کاتالوگ رابطه‌ای هستند و سرور رشتهٔ نمایشی آن‌ها را می‌سازد. مقدار ثبت‌نشده با «نامشخص» و گارانتی خالی با «ثبت نشده» نمایش داده می‌شود. unknown با false/خیر یکی نیست. تفاوت فقط بر مقدارهای ثبت‌شده و null محاسبه می‌شود.
- sharedURL شامل شناسهٔ عمومی محصول و SKU متناظر است و قیمت/حساب/توکن ندارد؛ بازکردنش preferences را نمی‌نویسد. محصول پنهان نمایش داده نمی‌شود، دستهٔ متفاوت جدول نمی‌سازد و SKU حذف‌شده به SKU دیگری تبدیل نمی‌شود. صفحه noindex است؛ cache مالی یا checkout ندارد.
- Lookup و Search موجود API از SQL واقعی استفاده می‌کنند؛ endpoint یا migration تازه لازم نشد. فقط خواندن موجودی با هویت case-insensitive سبد هماهنگ شد. Cart همچنان شناسهٔ تنوع را normalize می‌کند؛ BFF correlation، hydration، قیمت/موجودی ordinary و repeated-add همان هویت را رعایت می‌کنند. کلیدهای خارجی هلو همچنان opaque/BIN2 هستند. قیمت توافقی accepted-offer وارد registry عمومی نمی‌شود.

آزمون case در SQL پیش از اصلاح با Expected3/Actual0 شکست خورد و پس از اصلاح PUT/replay/پول صحیح و صفر رزرو را پذیرفت. ۸۰۱ unit،۴۷۵ SQL و۳۰۳ فروشگاه بدون fail/skip موفق‌اند. تنها DLL محصول تغییرکرده Inventory است و هر۱۳DLL API/unit/SQL/UIHarness مطابق‌اند. candidateهای اولیه و اجراهای ناموفق بازنویسی نشده‌اند؛ STATUS نام هر runtime و evidence را دارد.

QA نهایی دو محصول با هشت ویژگی comparable و یک ویژگی ممنوع، SKUهای uppercase، مقدار بالاتر از۲^۵۳ و long.Max دارد. بازیابی فقط‌خواندنی سبد پس از BFF fix، خالی‌کردن/ثبت/افزایش همان SKU از UI، یک ردیف تعداد۱→۲ با Stock ثابت و صفر رزرو/Order ثابت شدند. سپس از پنل خودQA با MFA تولیدی خودش، H منتشر و C به دستهٔ نمونه منتقل شد؛ فقط همان دو تغییر و uppercase استاندارد چهار SKU ذخیره‌شده طبق قاعدهٔ موجود مجاز بودند. قیمت‌ها، Stock و همهٔ مشخصات دیگر ثابت‌اند. چهار ستون، هشت unknown برای C، نبود ویژگی ممنوع و محدودیت چهار انتخاب دیده شدند.۱۵ پاسخ lookup خام مرورگر از مسیر BFF و۲ پاسخ متادیتای جدا، decoder تولید و hash بدون normalization را گذراندند؛ یک503 خواندن عمدی، حذف جدول قدیمی و retry آزموده شد.

BFF در حالت api و fixture خاموش است، اما API محلی فعلی عمداً `isPreview=true` و `dataSource=api` می‌دهد؛ این flag نمونهٔ توسعه، به معنی دیتای ثابت fixture نیست. provider مالی فعال نشده است.

ابزار viewport.set فعلاً مقدار1280 را نگه می‌دارد؛ screenshotهای1280 با نام mobile پذیرفته نشده و با نام diagnostic/desktop محفوظ‌اند. ورود native به برنامهٔ Codex نیز توسط ابزار مجاز نبود و دور زده نشد. یک درخواست محدود برای باریک‌کردن پنل توسط مالک ارسال شده؛ پذیرش موبایل تا مشاهدهٔ اندازهٔ واقعی باز است. QA مقایسه و پس ازآن QA نظرات هر دو باcleanupپیش‌فرضخودشان بسته/پاک‌اند؛مقایسه رویAPI/Nextاصلی۴۰ نیز محفوظاست. کل PDF و دست‌دوم/نظرات/اتصال زنده همچنان ناتمام‌اند.
