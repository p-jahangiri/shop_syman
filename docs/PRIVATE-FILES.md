# فایل خصوصی — پیوست تیکت۵۴ پذیرفته و محلی منتشر

برای CREDIT-01 و پیوست SUPPORT-01، فایل خصوصی از رسانهٔ عمومی Catalog جداست. ماژول Files فقط object رمز‌شده و مراحل ذخیره را مالک است؛ Support/Credit مجوز منبع و رابطهٔ پرونده را مالک‌اند و از قرارداد SharedKernel استفاده می‌کنند. هیچ URL عمومی یا presigned قابل اشتراک ساخته نمی‌شود. دانلود از API مجاز و no-store/noindex، attachment/nosniff/sandbox است؛ وجود ID مجوز نیست.

فایل حداکثر۸MiB با نام ساده و MIME/پسوند/signature سازگار JPEG/PNG/WebP/PDF پذیرفته می‌شود؛ این کنترل ادعای پاکی محتوای فعال PDF نیست و نمایش inline نداریم. اسکن واقعی ClamAV INSTREAM پیش از ذخیره لازم و قطع/timeout/پاسخ نامعتبر fail-closed است. اسکنر همیشه‌موفق محصول نداریم. پایهٔ پروتکل از [مستند رسمی clamd](https://docs.clamav.net/manual/Usage/ClamdProtocol.html) است؛ StreamMaxLength سرور باید حد ورودی را پوشش دهد.

هر object کلید تصادفی AES-256-GCM و nonce۱۲بایتی مستقل، tag۱۶بایتی و associated-data مقید به hash متادیتای ثابت دارد. کلید و نام فایل با purpose مستقل file/scope/owner/resource توسط keyring موجود Data Protection محافظت می‌شوند؛ plaintext یا کلید خام به objectstore نمی‌رود. SQL طول/hash ciphertext و facts ورودی را نگه می‌دارد. nonce با کلید تازه ساخته می‌شود؛ retry فقط همان plaintext/hash/nonce/key تاریخی را بازسازی می‌کند. [قاعدهٔ nonce .NET10](https://learn.microsoft.com/en-us/dotnet/api/system.security.cryptography.aesgcm.encrypt?view=net-10.0) مرجع است.

دو مرحله از نگه‌داشتن transaction SQL هنگام اسکن/شبکه جلوگیری می‌کند: رکورد Staged با actor+command/hash یکتا و IntentHash کاملِ فرمان ماژول (از جمله caption/locale) ابتدا پایدار، سپس نوشتن object ثابت و Stored؛ اتصال به منبع فقط در root Serializable و audit همان فرمان، Stored→Attached است. قطع پاسخ یا نتیجهٔ نامعلوم objectwrite باعث حذف خودکار object احتمالا موفق نمی‌شود؛ retry با همان command و input فقط همان object و رسید را بازیابی می‌کند. تغییر ورودی conflict است. objectهای Staged/Stored بی‌ارجاع تا cleanup با lease/بازبینی مستقل نگه داشته می‌شوند؛ حذف خودکار پیش از پیاده/پذیرش cleanup روشن نمی‌شود.

S3-compatible خصوصی با namespace ثابت و conditional-create، checksum و طول محدود استفاده می‌شود؛ کلید object فاقد نام/مالک است. [conditional writes رسمی S3](https://docs.aws.amazon.com/AmazonS3/latest/userguide/conditional-writes.html) مبناست؛ سازگاری سرویس نصب‌شده باید جدا آزموده شود. پیش‌فرض Disabled؛ filesystem فقط opt-in Development و خارج webroot. Production نیازمند endpoint HTTPS و credential/bucket خصوصی واقعی است. تست‌های capture SDK یا clamd پروتکل، شاهد سرویس واقعی/امضای تازهٔ ویروس نیستند.

پذیرش tamper/truncation/تغییر scope و metadata، کلید/نام حفاظت‌شده، retry/همزمانی/unknownwrite، owner/staff/MFA/Origin/حدها، attach/audit/rollback، UI/journal/قطع پاسخ و دانلود bounded انجام شده است.۹۵۱واحد/۶۵۸SQL واقعی/۳۸۹فروشگاه/۲۱۴پنل/۷proxy، S3 و ClamAV واقعی با امضای تازه و رد EICAR، دانلود دو سمت/hash دقیق،۱۲wireSQL/۵۶۶مرورگر و cleanup موفق‌اند. CSS نوار live مشترک برای دو ستون پنل اصلاح و artifact نهایی بازبینی شد. سپس backup، ارتقای افزایشی۵۴ و۱۰۸۶HTTP با حفظ داده‌های قبلی انجام شد؛ STATUS و `ticket-files54-source-acceptance.json`/`ticket-files54-main-release.json` مرجع‌اند.

**ذخیره‌ساز اصلی Disabled است.** پذیرش سرویس واقعی در منابع QA مستقلِ اکنون جمع‌شده، تنظیم vendor/bucket/credential/اسکنر تولیدی نیست. مدارک Credit هنوز متصل نشده‌اند؛ نگهداری/حذف، restore همراه objectها، mobile/load/nativeLinux و vendorهای بیرونی بازند. ClamQA روی مکARM با imageamd64 و emulation موجود اجرا شد. SeaweedFS4.51 صرفاً fixture بود؛ [انتشار رسمی](https://github.com/seaweedfs/seaweedfs/releases) و [Docker رسمی ClamAV](https://docs.clamav.net/manual/Installing/Docker.html) مرجع‌اند. [MinIO upstream](https://github.com/minio/minio) هنگام بررسی archived بود و fixture انتخاب نشد.

ورودی پیوست با MultipartReader محدود خوانده می‌شود و از IFormFile/ReadFormAsync که بالای۶۴KiB به فایل موقت دیسک منتقل می‌شوند استفاده نمی‌کند؛ [راهنمای رسمی ASP.NET10](https://learn.microsoft.com/en-us/aspnet/core/mvc/models/file-uploads?view=aspnetcore-10.0) مرجع است. حداکثر۲ درخواست فایل و۲ عملیات crypto/scan در هر process، filename/header/section محدود و digest واقعی سروری لازم‌اند. oversize مستقیم/file به413 و multipart نامعتبر/epilogue ردشده به400 می‌رسد؛ این تفاوت وضعیت به معنی پذیرش payload بزرگ نیست. نام دانلود با SetHttpFileName/RFC5987 و attachment/sandbox تولید می‌شود.


اصلی۵۷ adapter خصوصی Credit را اضافه کرد؛ Credit مالک رابطهٔ فایل به پرونده/consent/revision/کلید و Files مالک object است. CREDIT-DOCUMENTS/STATUS مرجع دقیق‌اند؛ mainFiles Disabled و retention/delete/restore همچنان بازند.
