# مرور عمومی آفلاین و SEO

وضعیت 2026-10-22: زیرساخت PWA و metadata پیاده و در خروجی production محلی بررسی شده است. فروش واقعی، Push و نصب روی دستگاه واقعی هنوز پذیرفته نشده‌اند.

## مرز داده و کش

| منبع | رفتار |
|---|---|
| HTML و RSC فروشگاه Next | هیچ پاسخ آن در Cache Storage نوشته نمی‌شود |
| API، حساب، آدرس، سبد، checkout، پرداخت، درخواست دارای Authorization | کش نمی‌شود؛ دادهٔ حساب یا مالی نسخهٔ آفلاین ندارد |
| قطع شبکه هنگام navigation | فقط پوستهٔ HTML عمومی و از پیش ساخته‌شده برگردانده می‌شود؛ مسیر خصوصی فهرست کالا را هم نمایش نمی‌دهد |
| `/pwa/catalog/fa.json` و `en.json` | DTO با allowlist مستقل: نام، برند، دسته، توضیح کوتاه و فقط SVG محلی عمومی؛ بدون قیمت، موجودی، گارانتی، روش خرید، پروفایل یا رسانهٔ امضاشده |
| DTO عمومی در Service Worker | network-first، اعتبارسنجی دوبارهٔ کلیدها/زبان/نوع پاسخ؛ نسخهٔ ذخیره‌شده حداکثر هفت روز و فقط هنگام قطع شبکه یا خطای 5xx |
| فایل‌های دارای hash در `_next/static` و SVG عمومی محلی | cache-first، حداکثر ۸۰ منبع؛ پاسخ private/no-store یا دارای Vary: Cookie/Authorization/* پذیرفته نمی‌شود |
| HTML/CSS/JS و دو فونت پوستهٔ عمومی | precache کوچک، بدون سرویس ثالث یا دادهٔ کاربر |

درخواست non-GET، RSC/prefetch، Authorization، Range، URL خارجی و query از کش منابع عبور نمی‌کند. شکست quota، پاسخ موفق آنلاین را خراب نمی‌کند. cache فقط با پیشوند اختصاصی `sayman-pwa-` پاک می‌شود. قیمت عمومی آنلاین هم در فهرست آفلاین ذخیره نمی‌شود. سفارش نهایی همیشه اتصال و کنترل سرور لازم دارد؛ همگام‌سازی پس‌زمینهٔ سفارش ساخته نشده است.

نسخهٔ worker با SHA-256 محتوای فایل‌های لازم ساخته می‌شود؛ `npm run build` و `npm run dev` مرحلهٔ تولید را اجرا می‌کنند. `public/sw.js` و فونت‌های کپی‌شده فایل تولیدی‌اند. مجوز فونت کنار آن‌ها کپی می‌شود. manifest هر زبان نام/شعار/رنگ فعلی CMS را می‌خواند؛ آیکن‌های PNG 180/192/512 از کد هندسی تولید می‌شوند.

## نصب و به‌روزرسانی

- راهنما: `/fa/install` و `/en/install`؛ لینک از فوتر موجود است. دکمهٔ نصب فقط با رویداد واقعی مرورگر و اقدام کاربر نمایش داده می‌شود؛ برای iOS راهنمای Safari / Share / Add to Home Screen وجود دارد.
- worker فقط در production و secure context فعال است؛ localhost محیط بررسی محلی است. نصب بومی یا مجوز اعلان در QA خودکار انجام نشده است.
- نسخهٔ تازه خودکار صفحه را reload نمی‌کند. کاربر از راهنما Update می‌زند؛ worker حضور هر پنجرهٔ حساب/خرید را بررسی می‌کند و در صورت وجود، فعال‌سازی را به تعویق می‌اندازد. reload فقط برای همان درخواست صریح و صفحهٔ عمومی است.
- دکمهٔ پاک‌کردن، فهرست و تصاویر ذخیره‌شدهٔ عمومی را پاک می‌کند؛ پوستهٔ عمومی باقی می‌ماند. خواندن بعدیِ آنلاین دوباره فهرست را دریافت می‌کند.
- `SHOP_PWA_ENABLED=false` برای غیرفعال‌سازی registration متعلق به همین برنامه و پاک‌کردن کش متعلق به آن است. تغییر این مقدار در process فروشگاه به restart همان process نیاز دارد.

## metadata و نمایه‌سازی

خانه، کاتالوگ/دسته و محصول عنوان و description داده‌محور دارند. CMS برای هر زبان `site.seo` اختیاری دارد: `title` حداکثر ۱۵۰ حرف، `description` حداکثر ۴۰۰ حرف، `shareImage` عمومی بدون credentials/query و `allowIndexing` بولی. فرم پنل draft/publish موجود همین تنظیمات را نگه می‌دارد؛ ذخیرهٔ SQL آن هنوز آزموده نشده است.

canonical و hreflang و OpenGraph/Twitter فقط از `SHOP_PUBLIC_URL` معتبر ساخته می‌شوند؛ Host درخواست و هدرهای proxy مرجع نیستند. origin نباید path/query/credentials داشته باشد. انتخاب variant در canonical محصول وارد نمی‌شود. canonical کاتالوگ فقط دستهٔ معتبر را نگه می‌دارد؛ جست‌وجو، sort و facetها noindex هستند. صفحات خصوصی از root، noindex می‌گیرند.

اجازهٔ نمایه‌سازی یک زبان نیازمند همزمانی این چهار شرط است:

1. `SHOP_ENABLE_INDEXING=true` در محیط و دامنهٔ HTTPS عمومی معتبر.
2. snapshot با `dataSource=api`.
3. `isPreview=false` از API؛ اکنون API عمداً هنوز true برمی‌گرداند.
4. انتشار `site.seo.allowIndexing=true` برای همان زبان.

در preview، robots همه را منع می‌کند و sitemap خالی است. sitemap فقط URLهای عمومی canonical زبان‌های مجاز را تولید می‌کند؛ تاریخ آخرین تغییر ساختگی ندارد. routeها dynamic هستند تا تغییر انتشار CMS به deploy جدید وابسته نباشد. Product/Offer و Breadcrumb در SSR فقط برای دادهٔ API غیر preview و origin معتبر تولید می‌شوند؛ قیمت رشتهٔ صحیح IRR است و نظر/امتیاز اختراعی وجود ندارد. JSON-LD قبل از قرار گرفتن در script برای `< > &` و جداکننده‌های Unicode escape می‌شود. اعتبار Rich Results با داده و دامنهٔ تولید هنوز آزموده نشده است.

## شواهد و محدودیت

- `npm test`: مجموع ۴۴؛ شامل ۹ آزمون حریم خصوصی/انقضا/به‌روزرسانی worker، ۶ آزمون SEO و آزمون مرز تصویر اشتراک.
- `dotnet test backend/tests/Shop.Tests`: مجموع ۶۷؛ پنج ورودی غیرمجاز SEO در این مجموعه‌اند.
- build تولیدی فروشگاه و پنل و TypeScript موفق‌اند.
- `python3 scripts/smoke-storefront-public.py`: ۱۴ بررسی HTTP روی production محلی؛ manifest دو زبان، ابعاد PNG، allowlist DTO، SSR و canonical در برابر Host جعلی، نبود Offer نمونه، robots/sitemap و هدر worker. گزارش `artifacts/checks/pwa-seo-smoke.json`.
- `scripts/verify-storefront-build.py` همان standalone را روی پورت آزاد 3000 بالا می‌آورد، ۱۴ smoke این سند و ۳۹ بررسی کاتالوگ/SSR را اجرا می‌کند و فقط فرایند متعلق به خودش را متوقف می‌کند؛ سپس چهار بررسی قطع API روی process مستقل پورت 3002 انجام می‌دهد. خود harness محلی نیز موفق اجرا و فرایند متعلق به خودش متوقف شد؛ source آن به CI اضافه شده و remote CI هنوز اجرا نشده است.
- مرورگر: توقف واقعی process فروشگاه؛ ۱۲ کالای عمومی در فارسی/انگلیسی، جست‌وجوی «انکر» با سه نتیجه، فیلتر کنسول با دو نتیجه، توضیح محصول و صفحهٔ خصوصی checkout بدون اطلاعات خرید بررسی شدند. سرور پس از آزمون بازگردانده شد.
- تعویق update با تب سبد باز، فعال‌شدن پس از بستن آن و رفع باقی‌ماندن اعلان نسخه، و پیام موفق clear در مرورگر بررسی شدند.
- نمای موبایل آفلاین: override عرض 375، عرض محتوای قابل استفاده و scrollWidth هر دو 360؛ بیرون‌زدگی افقی مشاهده نشد. override بازگردانده شد.

عکس‌ها در `artifacts/screenshots/`: `sayman-install-desktop.jpg`، `sayman-offline-persian.jpg`، `sayman-offline-private.jpg` و `sayman-offline-english-mobile.jpg`.

نصب/upgrade روی Android Chrome و iOS واقعی، Web Push با subscription پایدار/رضایت کاربر/محدودیت مجوز، بررسی کامل WCAG و معیارهای عملکرد، بلاگ/redirect و SEO اختصاصی قابل ویرایش هر محصول/دسته هنوز باقی‌اند. اجرای متصل CMS/کاتالوگ همچنان به SQL سالم نیاز دارد. این سند پذیرش کامل فاز ۸ نیست.

در برش تاریخی metadata-only شدن root، مسیرهای sitemap/DTO آفلاین هنوز snapshot کامل سمت سرور را می‌خواندند؛ ۱۴ HTTP این سند دوباره موفق شد و فهرست عمومی هر زبان پر ماند. در سورس جدید هر دو مسیر projection مستقل دارند؛ شواهد و پذیرش‌های باقی‌مانده در بخش‌های زیر ثبت شده‌اند. آن دادهٔ کامل به root مرورگر ارسال نمی‌شد.

## به‌روزرسانی projection آفلاین 2026-10-23

PWA در API mode اکنون فقط endpoint عمومی محدود `/api/catalog/{locale}/offline?limit=200` را می‌خواند؛ snapshot مالی کامل دیگر در این مسیر مصرف نمی‌شود. سقف دسته/محصول، فیلدهای مجاز، privacy و شواهد۲۱۲ بک‌اند/۹۸ فروشگاه و۱۶ HTTP در [OFFLINE-PROJECTION.md](OFFLINE-PROJECTION.md) است. دو SQL مثبت تازه هنوز اجرا نشده‌اند و این سورس روی اجرای اصلی منتشر نشده؛ سایت‌مپ در به‌روزرسانی بعدی همین سند شرح داده شده است. عددهای قدیمی این سند متعلق به برش ثبت‌شدهٔ قبل‌اند.

## به‌روزرسانی سایت‌مپ 2026-10-23

robots و sitemap در API mode اکنون از manifest کوچک و صفحهٔ۱۰۰۰ کلید Catalog استفاده می‌کنند. index ریشه فایل‌هایی مثل `/sitemap-fa-products-1.xml` معرفی می‌کند؛ rewrite داخلی بدون redirect و دامنهٔ قابل اعتماد، self/reciprocal alternate فقط برای ترجمهٔ واقعی، سقف فایل و پاسخ خطای بدون fallback دارد. Native API همچنان preview است و گیت انتشار باز نشده. شرح و محدودیت count/OFFSET در [SITEMAP-PROJECTION.md](SITEMAP-PROJECTION.md)؛۲۲۸ بک‌اند/۱۰۷ فروشگاه و۲۹ HTTP build واقعی موفق، دو SQL تازه فقط compile و انتشار اصلی هنوز باقی است. ادعای پذیرش SEO دامنهٔ واقعی یا معیارهای دستگاه نیست.
