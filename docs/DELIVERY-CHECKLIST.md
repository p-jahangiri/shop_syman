# چک‌لیست تحویل بخش‌به‌بخش سایمان

هر ردیف یک مسیر کامل کاربر یا مدیر است. شواهد و نسخهٔ فعال را کنار همان ردیف ثبت کنید. نتیجهٔ «پذیرفتهٔ محلی» به اجرای Production یا اتصال سرویس بیرونی تعمیم ندارد. اگر یک وابستگی بیرونی مانع است، قسمت داخلی و شرط بازگشت به آن را ثبت کنید و بخش مستقل بعدی را جلو ببرید.

## معیار پایان هر بخش

- [ ] سناریوی مشتری و مدیر، وضعیت‌ها، حالت خالی، خطا و تکرار درخواست روشن‌اند.
- [ ] دادهٔ واقعی، قرارداد API، حدود ورودی و خروجی، سطح دسترسی و تغییر هم‌زمان بررسی شده‌اند. برای تغییرات مالی یا موجودی، SQL واقعی و مسیر بازیابی لازم‌اند.
- [ ] فرم، جدول، وضعیت و پیام‌های پنل برای نقش‌های مجاز بررسی شده‌اند. اگر بخش اکشن مدیریتی ندارد، منبع دادهٔ پنل و علت نبود اکشن ثبت شده‌اند.
- [ ] مسیر فروشگاه فارسی و انگلیسی، نمایش موبایل، کیبورد، URL و حالت ناموجود یا قطع API بررسی شده‌اند. وضعیت SEO و کش مشخص است.
- [ ] باگ‌های قابل بازتولید اصلاح و آزمون رگرسیون اجرا شده‌اند. نسخهٔ فعال همان 3000/5080/3173 است.
- [ ] شواهد قبولی، محدودیت‌های باقیمانده و ردیف آمادهٔ بعدی ثبت شده‌اند.
