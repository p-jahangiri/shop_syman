# مشاهدهٔ Sayman در DataGrip

طبق درخواست مالک در 2026-10-30، یک اتصال مستقل با نام `Sayman · Local` در DataGrip همین مک اضافه و آزمایش شد.

| گزینه | مقدار |
|---|---|
| نوع | Microsoft SQL Server |
| میزبان | `127.0.0.1` |
| پورت | `11433` |
| دیتابیس | `Sayman` |
| احراز هویت | User & Password؛ حساب SQL موجود |
| طرحواره‌های نمایان | `Sayman:*` |
| نگه‌داری رمز | For session؛ فراموش‌شدن پس از قطع اتصال |

رمز موجود پروژه در فیلد پوشیده وارد شد و در این راهنما یا شواهد ثبت نشده است. اگر DataGrip پس از قطع اتصال دوباره رمز خواست، همان `SQL_SA_PASSWORD` محلی استفاده می‌شود؛ رمز ورود پنل فروشگاه، رمز SQL نیست.

در ستون Database Explorer مسیر `Sayman · Local → Sayman → catalog → tables` را باز کنید؛ برای مشاهدهٔ داده، جدول را انتخاب و «Edit Data» را بزنید. طرحواره‌های دیگر مانند `inventory`، `sales`، `identity`، `cms` و `support` هم در همان دیتابیس در دسترس‌اند. DataGrip می‌تواند داده را تغییر دهد؛ بررسی این اتصال فقط خواندنی بود و کاربر/مجوز/جدول/داده‌ای در SQL تغییر نکرد.

آزمون خود DataGrip نتیجهٔ Succeeded، SQL Server16.0.4225 وping17ms داشت. جدول `catalog.Products` واقعاً باز و۲۷ردیف دریافت شد. درایور موجود SSL:no گزارش کرد؛ تنظیم TLS/گواهی در این کار تغییر نکرد و این مشخصات فقط برای اتصال محلی‌اند. سرویس‌های فروشگاه و اتصال‌های دیگر تغییر نکردند.
