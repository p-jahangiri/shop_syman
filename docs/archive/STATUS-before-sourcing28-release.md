## برش بسته‌شده: CSV و مدیریت بازار

[MARKET-CSV](MARKET-CSV.md) قرارداد و شواهد دقیق را دارد. UTF-8 محدود/کوتیشن/newline، منبع+شناسه برای upsert، اتصال صریح model_id، ویژگی‌های تایپ‌دار و ارقام فارسی، preview فقط خواندنی و commit اتمیکِ کل فایل با receipt actor+UUID/hash و نسخهٔ listing/model/metadata پیاده‌اند. receipt در همان transaction Catalog+Market+audit ذخیره می‌شود. retry دستی همان body/UUID نتیجهٔ قبلی را می‌خواند؛ تغییر بدنه409 است. هیچ CSV خام یا credential در receipt ذخیره نمی‌شود.

پنل فهرست۵۰تایی/seek/فیلتر، ساخت مدل بدون SKU و ویرایش مشترک مدل/منبع، فرم پنج نوع ویژگی با decimal رشته‌ای، راهنمای پویای شناسه/گزینه‌های CSV، preview/خطای ردیف/ثبت، پیگیری رسید و unknown/retry دارد. draft و انتشار بازار از فروشگاه مستقل‌اند؛ هیچ قیمت/Stock/روش خرید موجود عوض نمی‌شود. نقش خواندنی ابزار نوشتن ندارد و backend مستقل از UI مجوز را می‌سنجد. راهنمای زنده از metadata می‌آید، نه شناسهٔ hardcode.

پذیرش نهایی: **۴۶۲/۴۶۲ واحد بک‌اند، کل۱۵۲/۱۵۲ SQL واقعی (صفر fail/skip)،۵۷/۵۷ تست پنل،۲ proxy server،۷ decoder روی پاسخ واقعی SQL، typecheck و build پنل موفق‌اند**.۹ SQL تازه CSV/ویرایش شامل rollback خرابی receipt، رقابت UUID، stale metadata و حفظ قیمت‌ها هستند. Catalog/Market model بدون تغییر جامانده و market.sql idempotent به۲۴ به‌روز است.

مرورگر واقعی با حساب/MFA تولیدشدهٔ خود QA: ساخت/ویرایش، رد گزارش ناقص، پیش‌نمایش بدون write در SQL، CSV ایجاد/به‌روزرسانی، مبلغ9007199254740993 بدون افت دقت، خطای فارسی برند، راهنمای دسته/ویژگی، موبایل بدون overflow و منوی بسته خارج از AX، پیگیری رسید موفق‌اند. پاسخ پس از موفقیت SQL عمداً قطع شد؛ unknown، قفل فایل، حفظ همان UUID/body هنگام جابه‌جایی پنل و retry دستی/replayed با **یک مدل/یک receipt** پذیرفته شدند. شبکهٔ مرورگر ابتدا یک قطع منفرد را خودش retry کرد؛ سپس gate کنترل‌شده دو پاسخ را قطع کرد تا unknown دیده شود. این جای provider مالی نیست. شواهد market-csv-ui-acceptance.json/response-loss.json و تصاویر market-csv-ui-*.jpg محفوظ‌اند. console عادی صفر؛ خطای شبکهٔ عمدی جزو آزمون است. انتخاب فایل واقعی از file chooser، همهٔ نوع ویژگی‌ها در مرورگر و نقش محدود/دو نشست UI جدا هنوز پذیرفته نشده‌اند؛ parser/نقش/رقابت در SQL پوشش دارند.

journal فایل/فرمان فقط RAM و مقید به حساب است؛ ناوبری پنل آن را حفظ و logout/بستن تب پاک می‌کند. پس از reload باید UUID برای GET receipt نگه داشته شود؛404 پایان فرمان در حال اجرا را ثابت نمی‌کند. هیچ ذخیرهٔ CSV در localStorage وجود ندارد.
