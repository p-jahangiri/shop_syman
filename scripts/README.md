# ابزارهای عملیات سایمان

- `local/` ساخت آفلاین پنل و فروشگاه و پاک‌سازی خروجی‌های قابل‌بازسازی.
- `verification/` بررسی پاسخ‌های ثبت‌شدهٔ HTTP و تطبیق آن‌ها با قراردادهای TypeScript. ورودی هر ابزار در راهنمای همان قابلیت آمده است.
- `tests/` آزمون‌های ابزارهای عملیات با `python3 -m unittest discover -s scripts`.
- `serve-main-*` راه‌اندازی بسته‌های پذیرفته‌شده روی پورت‌های اصلی. نام این فرمان‌ها در descriptorهای اجرای محلی ثبت شده است.
- `deploy-production.sh` و `production_release.py` بررسی و انتشار بستهٔ تولید.
- ابزارهای دیگر ریشه شامل راه‌اندازی محیط، پشتیبان‌گیری، آزمون SQL، بررسی سلامت و ابزارهای انتشار نسخه‌های ثبت‌شده‌اند. ابزار نسخه‌دار را طبق سند همان نسخه اجرا کنید.
